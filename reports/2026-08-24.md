## dani-garcia/vaultwarden

### 项目定位

Vaultwarden 是一个用 Rust 编写的非官方 Bitwarden Client API 服务端实现（前身为 bitwarden_rs），核心解决的问题是：官方 Bitwarden 服务端资源占用重，不适合小型自托管环境，而 Vaultwarden 让用户能在低配硬件上自建密码管理服务，同时继续复用官方 Bitwarden 全套客户端。在技术栈层级上，它属于安全域的应用层基础设施，是密码/密钥管理场景的后端服务，几乎全部以容器方式（Docker Hub / ghcr.io / Quay.io 三渠道分发）部署于自托管环境。

**竞品/互补项目**（注：数据中未提供同域关联项目，以下基于 README 中明确引用的对象及生态常识）：
- **官方 Bitwarden 服务端**（直接竞品）：README 明确将其定位为"资源过重的官方服务"，Vaultwarden 的存在意义就是其轻量替代
- **官方 Bitwarden 客户端**（强互补）：Vaultwarden 非全栈产品，其价值完全建立在"替换服务端、复用官方客户端"的共生关系上

**生态位置**：在"自托管 Bitwarden 兼容服务端"这一细分赛道中，Vaultwarden 是事实上的龙头——66,088 Stars 属于该量级的头部项目，且 Fork/Star 比仅 0.05，说明绝大多数用户是直接消费部署而非二次开发，这是成熟基础设施软件的典型消费型结构。
